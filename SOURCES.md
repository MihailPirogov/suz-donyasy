# Источники данных «Сүз дөньясы» (рабочее название)

| Что | Источник | Лицензия | Коммерческое использование | Как используется |
|---|---|---|---|---|
| Татарские слова, русские переводы, примеры, формы, синонимы | Русский Викисловарь, татарские статьи (https://ru.wiktionary.org, категория «Татарский язык»), машинное извлечение Wiktextract: https://kaikki.org/ruwiktionary/Татарский/ (11 916 слов / 12 206 статей, файл `src/ru_tt.jsonl`) | CC BY-SA 4.0 (+ GFDL) | **Да**, при указании авторства (Викисловарь, ссылка на лицензию) и с той же лицензией на производные данные (наши карточки/словарь — CC BY-SA 4.0; код игры, по общепринятому толкованию, под ShareAlike не попадает — это стоит подтвердить юристу перед магазинами) | единственный источник отгружаемых переводов и карточек |
| Доп. татарские слова (только бонусные), англ. запасной перевод | English Wiktionary через kaikki.org: https://kaikki.org/dictionary/Tatar/ (1 984 слова, `src/en_tt.jsonl`) | CC BY-SA 4.0 (+ GFDL) | Да, те же условия | проверка бонусных слов |
| Частоты слов | Дамп татарской Википедии https://dumps.wikimedia.org/ttwiki/latest/ (`ttwiki-latest-pages-articles.xml.bz2`, 01.10.2026) → `tools/ttwiki_freq.py` → `src/ttwiki_freq.json` | тексты CC BY-SA 4.0; мы используем только счётчики (факты), текст не отгружается | Да | порядок сложности уровней |

Проверено, но НЕ используется в отгружаемых данных:
- Apertium `apertium-tat-rus` (https://github.com/apertium/apertium-tat-rus, ~6 000 пар тат.→рус.) и `apertium-tat` (морфология, ~60 тыс. строк lexc) — **GPL-3.0**. Коммерция разрешена, но копилефт GPL для данных внутри игры неудобен → лежат в `src/` только для справки/будущей проверки.
- hunspell-tt (2008) — GPL-2.0 (не скачивали).
- Национальный корпус «Туган тел» (tugantel.tatar, АН РТ, база данных № 2025620055) — открытой лицензии нет, только поиск на сайте → не используем. Письменный корпус corpus.tatar — «только некоммерческие научные и учебные цели» → не используем.
- Wikidata Lexemes (CC0) — всего 11 татарских лексем, бесполезно.

Музыка: нет. Звуки — синтез WebAudio в коде (js/sound.js). Фоны глав — 50 фотореалистичных изображений, сгенерированных ИИ (GenerateImage, подборка и проверка вручную, `src/bg_stage/sources.json`), апскейл Real-ESRGAN realesr-general-x4v3 (BSD-3); процедурный SVG (js/art.js) — запасной вариант. Иконка — img/icon.svg (своя). Музыка трейлера — синтез в tools/make_trailer.py.
